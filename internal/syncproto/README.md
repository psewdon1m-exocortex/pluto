# Inactive sync protocol reader

This package reads the shared candidate in Saturn `docs/implementation/SYNC_PROTOCOL_CANDIDATE_v1.md`. It is not called by Copy, Serve or the existing planner. A validated value supplies wire shape only, never source completeness, current namespace authority, baseline adoption or permission to publish.

`testdata/golden.v1.json` is byte-identical to the shared Saturn fixture; its historical qualification label describes the original fixture cohort. `boundaries.v1.json` retains 163 cross-language cases from qualified v3. Large byte-budget and deterministic exact64 cases are generated by tests. Set SYNC_WIRE_CORPUS_PATH only for the separately recorded full differential audit corpus.
